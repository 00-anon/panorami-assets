# panorami-assets

Immagini usate dal sito [panorami.eu](https://panorami.eu).

| File | Che cos'è |
|---|---|
| `glasshouse-360.jpg` | Panorama 360° equirettangolare, 6144×3072, mostrato in cima alla home. |
| `glasshouse-360-preview.jpg` | La stessa immagine a 640×320, usata come anteprima mentre il panorama si carica. |

Origine: «Glasshouse Interior» di Dario Barresi, da [Poly Haven](https://polyhaven.com/a/glasshouse_interior),
licenza CC0 (pubblico dominio). Qui è ridimensionata e ricompressa per il web a partire dal JPG 8K.

Il sito le carica tramite jsDelivr da una versione fissa (`@v1`): per cambiare un'immagine si aggiunge un file
nuovo e si crea una nuova versione, senza toccare quelle già pubblicate.
